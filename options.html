설정

Changelink의 계정 연결, 동작 방식, 댓글 템플릿을 관리합니다.
변경 사항은 저장 즉시 열려 있는 Gerrit·Jira 탭에 반영됩니다.

change 페이지 주소에서 /c/ 앞까지. 예: https://gerrit.example.com
Jira 를 열었을 때 주소창의 맨 앞부분. 예: https://yourcompany.atlassian.net
저장하면 이 두 사이트의 접근 권한을 묻습니다. 허용해야 동작합니다. Jira 는 Cloud 기준입니다.
API 토큰은 Atlassian 계정에서 발급한 값을 사용하세요.
Jira 이슈에서 관련 change 를 찾을 때 씁니다. Gerrit 설정의 HTTP Credentials 에서 발급합니다. 비워 두면 브라우저의 Gerrit 로그인을 씁니다.

동작 설정

상태 목록은 저장된 Jira 계정에서 자동으로 불러옵니다.

Jira 댓글 템플릿

아래 플레이스홀더를 자유롭게 조합하세요. 비워두면 기본값이 사용됩니다.

플레이스홀더치환 내용
{title}커밋 제목 (첫 번째 줄)
{body}커밋 메시지 본문 (제목·jira 라인 제외)
{branch}타겟 브랜치명
{change_num}Gerrit change 번호 (예: 12345)
{change_id}Gerrit Change-Id (예: Iabc123...)
{project}저장소 경로 (예: platform/myapp)
{owner}change 작성자 이름
{date}반영 일시 (submit 시각, 없으면 빈칸)
{url}Gerrit change 링크 (클릭 가능)

도움말

  • API 토큰 발급: Atlassian 계정 설정 에서 발급하세요.
  • Gerrit HTTP 비밀번호 (선택): Gerrit 오른쪽 위 설정 → HTTP Credentials 에서 Generate New Password 로 발급합니다. 사용자명도 같은 화면에 있습니다.
  • Gerrit change 페이지에서 툴바 아이콘을 클릭하면 popup이 열리며 이슈 조회/웹링크 추가/코멘트 생성을 실행할 수 있습니다.
  • Jira 이슈 페이지에서 툴바 아이콘이나 빠른 실행 버튼을 누르면 커밋 메시지에 그 이슈키가 들어간 Gerrit change 목록이 보입니다.
  • 이슈 키는 change 제목(예: [PROJ-123] Fix bug) 또는 커밋 메시지의 jira: PROJ-123 형식에서 자동 추출됩니다.
  • 연결 테스트는 Jira 인증 여부만 확인하며 응답 본문은 읽지 않습니다.
